# Canonical Command Examples

## Voice
"Jarvis, open Chrome."
-> `open_app("Chrome")`

"Set volume to 40."
-> `set_volume(40)`

"Search the web for today's weather."
-> online `WEB_SEARCH`

"Turn off the computer."
-> high-risk action -> confirmation required.

## Gesture
Pinch -> click.
Two-finger movement -> scroll.
Swipe right -> next.
Open palm -> stop/pause.
Thumbs up -> confirm.

## Multi-step
"Open Chrome and search for Java interfaces."
1. open Chrome
2. verify
3. search
4. report result

## Ambiguous
"Open that."
If multiple recent targets exist, ask which one.
